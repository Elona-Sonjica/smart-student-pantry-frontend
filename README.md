# Smart Student Pantry

## About the Project

Smart Student Pantry is a grocery subscription application that provides affordable and convenient meal and grocery options for students.

The platform aims to help students manage their grocery needs through affordable subscription packages, making it easier to access essential food items.

## Main Features

* Student registration and login.
* Browse available grocery packages.
* Add grocery items to a shopping cart.
* Manage grocery subscriptions.
* Place and manage orders.
* Track order status.

## Technologies Used

* Java
* Spring Boot
* PostgreSQL
* HTML
* CSS
* JavaScript
* Supabase

## Project Purpose

The purpose of Smart Student Pantry is to make grocery shopping more affordable, convenient and accessible for students.
